# Testes do grupo

Testes escritos pelo grupo (com o copiloto) a partir dos critérios
"Dado / Quando / Então" das histórias. Complementam os testes do professor,
não os substituem.

Esta pasta é livre: o grupo cria e altera à vontade. Revise cada teste que o
copiloto escrever: um teste que passa sempre não prova nada. Veja o teste
falhar antes de confiar nele.

Use as fixtures de `tests/conftest.py` (`cliente`, `caminho_banco`, `llm_falsa`).
